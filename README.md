# 📈 Stock Price Tracker

A simple stock price tracking web application built using **HTML, CSS, and JavaScript**.

The application displays stock information and dynamically shows whether the stock price has **increased, decreased, or remained the same** compared with the previous price.

## 🚀 Features

- 📊 Displays stock name
- 🔤 Displays stock symbol
- 💰 Displays current stock price
- 🕒 Displays the current time
- ⬆️ Shows an up arrow when the price increases
- ⬇️ Shows a down arrow when the price decreases
- ➡️ Shows a same arrow when the price remains unchanged
- 🔄 Automatically updates the stock data every 2 seconds
- 📱 Simple and responsive interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- JavaScript ES Modules
- DOM Manipulation
- `setInterval()`
- `createElement()`
